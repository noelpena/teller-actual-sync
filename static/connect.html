🧵 Quiltt Setup

Configure your Quiltt credentials before linking your bank account.

Where do I get these?

Sign up at the Quiltt Dashboard, create an Environment, copy your API Key secret, then create a Connector and copy its ID. No mTLS certificates needed.

Dashboard → Environment → API Keys
Dashboard → Connectors → your Connector → ID

Securely link a bank account through Quiltt. Your credentials are never stored by this app — only account IDs used for syncing.
